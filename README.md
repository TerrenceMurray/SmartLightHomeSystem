### Smart Home Lighting Control System
A multi-user lighting management system demonstrating advanced OOP design patterns

**UML Class Diagram**
![asg2-oop](https://github.com/user-attachments/assets/8d609ba2-b4f4-45ec-bb87-cb3c357ed636)

**Patterns Implemented:**
- Composite Pattern for hierarchical device management
- Command Pattern with full undo/redo support
- Observer Pattern for real-time notifications

**Key Features:**
- Multi-user command execution with audit trails
- Recursive grouping (rooms, zones, entire house)
- Real-time updates across all user displays
- Timestamp-based command history

**Tech Stack:** Java, Design Patterns, UML
